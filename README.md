## 『小助手』Github - 过滤库

屏蔽 Github 里，不想看到的库，如：各种 leetcode，oj 等。

### 功能
1. 支持三种过滤方式，关键字过滤，开发者过滤，仓库过滤
2. 支持 搜索结果界面过滤，Topic 界面过滤
3. 显示过滤的数量，以及过滤了哪些仓库
4. 快捷过滤方式，点击图标，选择过滤方式，无需手动输入关键字
5. 脚本菜单，快捷设置入口
